# T005 接力脚本：开工留言与进度心跳

状态：待发布（T002 合并后立即发布，排在 T004 之前，属于小任务）
分支：`codex/T005-relay-heartbeat`（由 Claude 预先建好）

## 背景

2026-09-28 首次自动接力时，ChatGPT 已在后台开工（本机日志 20:20:54 “开始 PR #3”），但 GitHub 上没有任何痕迹，Claude 和用户都无法确认它是否在干活，只能让用户去终端看日志。

## 要做

1. `tools/codex-relay.mjs`：开始处理一条任务时，立即在该 PR 上留言“已接手，开始处理”（附评论链接和开始时间）。
2. 处理期间每 15 分钟更新同一条留言（编辑，不刷屏）：已运行时长、最近一次日志时间。不要贴出完整日志、密钥或本机路径。
3. 结束时照常留最终结果留言，并把“已接手”那条改成“已结束”。
4. 进程中断后重启时，把仍标为“处理中”的那条留言改为“中断，需要检查”。
5. 单元测试覆盖以上状态变化；`npm run verify` 通过。
6. 在用户的 Mac 上重新安装接力服务，使新版本生效（按 `docs/CODEX_RELAY.md` 的安装步骤），确认日志里出现新版本启动记录。**注意：重新安装会重启正在运行的接力进程，必须在没有任务执行时进行。**

## 验收标准

- 自测：对本 PR 发一条带接力标记的测试评论，能看到“已接手 → 进度 → 已结束”三个阶段。
- 执行记录写明实际验证过程和结果。
