## 要做

1. **素材风格规范** `art/style/STYLE.md`：从目标图总结配色（墙面、墙顶、浅色地砖、白色座面与青绿椅架、描边颜色和粗细）、光照方向、等轴角度（2:1）、人物比例（约 7 头身）、素材尺寸与锚点规则（脚底或底面中心）。之后所有素材都按这份规范生成。
2. **生成诊室素材**（用图像生成，透明背景 PNG，与目标图同风格、同角度、同光照），放在 `v2/assets/`：
   - 家具设备：诊桌、电脑显示器、医生椅、患者椅、诊床、边柜、洗手池、落地植物、墙上的挂画或阅片灯。每件只需一个朝向，另一朝向用水平镜像。
   - 人物：医生（白大褂）坐姿、站姿；患者坐姿、站姿。正面和背面各一张（左右用镜像）。
   - 每件素材在 `v2/assets/manifest.json` 登记：文件名、占地格数、锚点、朝向、能否镜像。
   - 生成后做必要的清理：去背景、裁边、统一尺寸与描边；同一批素材光照方向和描边必须一致。
3. **引擎改造**（在 `v2/` 上改，不另起炉灶）：
   - 地板、墙、墙顶、门按目标图配色和描边重画；诊室和走廊均用参考图的浅色地面与细砖缝。
   - 家具和人物改为从 manifest 读取素材绘制，仍按 T001 的深度排序；点选改为按素材的不透明像素判定（取代 `personHit` 里的写死常数）。
   - 保留 T001 的拖动、缩放、点选、按需重绘。
4. **验证场景**：在 `/v2/?scene=clinic-room` 摆出一间诊室加一小段走廊：医生坐诊、患者就坐，另一名患者站在门口。
5. **对比截图**：390×844、3 倍像素下截两张，默认视角 `art/screens/T004/room.png`，放大视角 `art/screens/T004/room-zoom.png`；再做一张与目标图诊室局部的并排对比 `art/screens/T004/compare.png`。

## 验收标准

1. `npm run verify` 通过。
2. 三张截图齐全。和目标图诊室局部相比，配色、描边、光照、人物比例一致，家具之间风格统一，没有明显“拼贴感”（素材大小、角度、光照互相打架）。
3. 执行记录说明：素材是怎么生成和清理的（用了什么工具、试了几次）、哪些素材达不到要求、做完整家医院大约还需要多少件素材、主要风险是什么。
4. PR 正文逐条自查。

### 画面自查与限制

白/青绿配色、少描边、正常比例与简化等轴方向已落实，坐姿已在场景里对齐座椅。并排比较仍有差距：诊桌/柜体明暗比参考更有体积感，部分人物脸部细节在姿态之间不完全一致；镜像会翻转原素材光照；诊床带靠背与参考的平床不同。没有把这些差异宣称为完全匹配。最终画风采用由用户看实际场景决定。

目前只满足一间诊室试验，不宣称整院美术完成。估计扩展现有医院还需约25–40种家具设备，另需护士/技师/不同患者及行走动作约40–80张姿态素材；属于资产盘点前的工程估计。主要风险为各姿态身份一致性、镜像光照、座椅锚点与大件遮挡、像素点击目标在手机默认缩放下偏小。没有手机真机或Safari性能证据。
