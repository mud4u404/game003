# T006 可玩原型 v0.1：模拟接入画面

状态：已完成（由 Claude 实现：夜间用户 Mac 睡眠，本机接力暂停）
依据：`GAMEPLAY.md` 2、3、4.3、5、6、9 节；`docs/PLAYTHROUGH.md` 第 1 天至第 2 周；T001 场景（`v2/`）；T002 知识库（`data/`）；T003 引擎（`v2/src/sim/`）
分支：`claude/T006-playable`

## 目标

用户醒来打开 `/v2/`，能玩到第一个可玩原型：医院按真实时间自己运转，看得到病人进出、就诊；点任何人能看到真实病历；汇报里能发现问题；改规则能改变后续结果。画面沿用 T001 现有素材（新画风由 T004 另行替换）。

## 要做

1. **接入引擎**：`/v2/` 启动 T003 引擎，按现实时间推进。首次打开建立新医院（默认配置来自数据文件），营业时间 8:00–17:00（本地时间）。关闭页面后再打开，用 `advanceTo` 补算离线期间的就诊，结果与一直开着一致。
2. **存档**：引擎状态存 `localStorage`（带版本号）；存档损坏时不覆盖，提示并提供“新建医院”。不读写旧原型的存档键。
3. **人物走动**：病人从急诊入口/正门进入，按流程去分诊台、候诊椅、诊室、检验科或放射科，然后离开；员工待在各自岗位。用房间门洞和走廊的路点做直线插值移动即可，不需要复杂寻路。人物位置由模拟状态决定，画面只负责表现；坐下时对齐座椅，躺下时对齐床或检查台。
4. **病历卡**：点任何病人，底部弹出真实病历（`GAMEPLAY.md` 第 6 节 1–6 项）：进行中的病人显示当前环节和已完成的步骤；已离院的病人可在汇报里查到。点员工显示姓名、岗位、当前工作、疲劳。
5. **汇报**（底部“汇报”入口）：今日报表，内容包括接诊数、平均候诊、最长候诊、转诊数及原因、误诊/返诊数、收入。每个数字都能点开，看到对应病人列表，再点进病历。另有一份“离线简报”：打开游戏时如果离开超过 30 分钟，先弹出这段时间的摘要。
6. **规则**（底部“规则”入口）：检查策略（精简 / 规范 / 全面）、接诊范围（能力外直接转诊 / 尽量处理）两条可切换，立即对之后的病人生效，并在汇报里看得出差别。
7. **人事、资金**：人事显示员工列表和状态（只读）；资金显示现金和今日收支（简化）。“建设”仍为“即将开放”。
8. **非营业时间**：画面显示“已下班”和下次开门时间，离线简报照常工作。
9. **开发者验证入口**：可用 URL 参数把引擎时钟设到指定时刻，并以倍速运行，**只用于测试截图，玩家界面不出现，也不写入玩家存档**（用独立存档键）。

## 不做

- 不做建设模式、招聘、贷款、院长助理、新病种、新画风素材。

## 验收标准

1. `npm run verify` 通过；新增测试覆盖存档恢复、离线补算一致、规则切换生效、病人位置与模拟状态一致。
2. 用开发者入口在 390×844、3 倍像素下截图：营业高峰的医院全景 `art/screens/T006/busy.png`；点开进行中病人的病历 `record-live.png`；点开已离院病人的完整病历 `record-done.png`；今日汇报 `report.png`；离线简报 `offline.png`。
3. 在正常 `/v2/` 入口（非开发者模式）实际运行至少 10 分钟真实时间（营业时间内），确认有病人进来、走完流程、离开，没有卡住不动的病人；非营业时间则说明验证方式。控制台无错误。
4. PR 正文逐条自查；执行记录写明未验证的部分。

### 实现

- `v2/src/app.js` 重写：载入 `data/`（按 `manifest.json`）、建立或恢复引擎、每秒按真实时间 `advanceTo`，分钟变化时同步人物、刷新顶栏和打开的面板；每 30 秒及页面隐藏/关闭时存档。
- `v2/src/actors.js`：模拟状态 → 人物位置。分诊排队、候诊椅（12 个，满了站在大厅边）、诊室（内科坐诊凳 / 外科诊室站位）、检验采血椅、X 光检查床、处置室三张床；跨房间沿门口走（1.4 格/秒），离院走出正门后移除。员工在各自岗位，检验技师做检查时走到采血椅旁。
- `v2/src/people-nodes.js`：人物绘制节点（沿用 T001 画法），每次更新与静态场景一起深度排序。
- 面板：病历卡（分诊级别、当前环节、主诉、症状、接诊与候诊时间、初步考虑、检查及结果、诊断、处置与转诊原因、结局或随访揭晓日、费用、问题标记、就诊经过、上次/返诊病历链接、示意数据声明）；员工卡；汇报（门诊日报，含“此刻正在候诊”，每个数字下钻到病人列表再到病历，可翻看前一天）；规则（两条可切换，立即生效）；人事（员工列表）；资金（今日/昨日/累计收入，说明支出未接入）；建设（即将开放）；离线简报。
- 顶栏：日期时间、营业/下班状态、今日收入、汇报按钮带提醒数（离开和返诊误诊）；下班时显示下次开门时间。
- `data/` 由服务器开放访问（T003 已改）。
