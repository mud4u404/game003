# T003 就诊模拟引擎核心

状态：已完成（由 Claude 实现：夜间用户 Mac 睡眠，本机接力暂停）
依据：`GAMEPLAY.md` 2、3、6、9 节，第 0 节的时间规则；`docs/PLAYTHROUGH.md` 第 1 天至第 2 周；T002 的 `data/`
分支：`claude/T003-sim-core`（原 `codex/T003-sim-core` 的 PR #4 已关闭）

## 目标

写出不带画面的模拟引擎：患者按知识库数据产生、到院、走完就诊流程、得到结局，并留下完整病历。引擎要能按真实时间持续运行，离线后能补算，结果可以复现。

## 要做

1. `v2/src/sim/` 下的纯逻辑模块，不依赖浏览器（可在 Node 里运行和测试）。
2. **时间**：游戏时间等于现实时间，没有倍速。引擎提供 `advanceTo(timestamp)`，一次推进任意时长（例如离线 9 小时），结果必须与逐分钟推进完全一致。
3. **随机可复现**：使用带种子的随机数；同一种子、同一操作序列，结果相同。
4. **患者产生**：按 `data/diseases` 的发病率、年龄权重、季节系数，以及一个简化的地段人口（先用老城区一组参数，写在数据文件里），产生到院患者。首批只有门诊，营业时间暂定每天 8:00–17:00。
5. **就诊流程**：分诊 → 候诊 → 医生问诊（生成怀疑列表）→ 按检查策略开检查 → 诊断（可能误诊）→ 治疗或转诊 → 结局。每一步占用对应的员工、房间、设备和时长；资源不够就排队。检查项目在本院做不了时，按规则转诊或凭经验判断。
6. **员工**：医生、护士、检验技师、放射技师、药剂师。属性至少有能力、速度、疲劳；疲劳随工作上升、休息下降，影响速度和误诊概率。
7. **规则**：检查策略（精简 / 规范 / 全面）、接诊范围（能力外直接转诊 / 尽量处理）两条先接入，改变规则会改变后续患者的流程。
8. **病历**：每个患者一份完整记录，内容满足 `GAMEPLAY.md` 第 6 节 1–6 项；误诊在返诊时补标“初诊误诊”。病历是模拟的事实，汇报以后从这里统计。
9. **存档**：引擎状态可以序列化成 JSON 并恢复，恢复后继续推进，结果与不中断时一致。
10. **初始医院**：用 T001 场景里的房间和人员作为默认配置，放在数据文件里，不写死在代码中。

## 不做

- 不接画面、不做界面、不做汇报、不做建设和招聘操作、不做财务细节（只记录每个患者的费用）。
- 不写新病种，数据只用 T002 的内容。

### 实现

- `v2/src/sim/engine.js`：分钟级确定性引擎。`advanceTo(ms)` 逐分钟推进，因此一次推进与分段推进逐字节一致；全部状态（含随机数状态）在 `engine.s`，`serialize()` / `Engine.restore()` 存档恢复。
- `v2/src/sim/rng.js`（可存档随机数）、`names.js`（虚构人名）、`stats.js`（日报与离线简报，数字附病历 id 列表以便下钻）、`load-node.js`（Node 端读数据）。
- `data/hospital-default.json`：老城区 8 万人、市场份额 20%、8:00–17:00 营业、19:00 停止服务；6 名员工沿用 T001 场景人物（内科陈明、外科林远、分诊护士周宁、处置护士林静、检验刘川、放射何川）。T001 的“病房”在引擎里作为“外科诊室 · 处置室”（兼心电图）。`data/manifest.json` 供浏览器按清单加载病种。
- `tools/sim-day.mjs`：命令行模拟一天并打印摘要和病历样例。
- `server.mjs` 允许访问 `data/`；`tests/v2/check-syntax.mjs` 改为递归检查 `v2/src` 子目录。

### 规则与数据口径（均为游戏规则，写在代码常量中）

- 到院：各病种门诊就诊人次率 × 人口 × 市场份额 ÷ 365，按营业分钟均摊，泊松抽样；只生成 18 岁及以上成人。
- 流程：分诊 4 分钟 → 按专科分给医生（本院无对应专科则给排队最短的医生）→ 问诊 10 分钟 → 按检查策略开检查（诊室内的血压、血氧当场完成）→ 检查排队、出结果 → 医生看结果 5 分钟 → 诊断 → 门诊处置 8 分钟（需夹板 15 分钟）或转诊。时长按员工速度和疲劳调整。
- 诊断：初步判断正确率取决于医生能力、病种难度、疲劳（返诊加成）；**误诊只来自“初步判断错且检查未能纠正”**，与真实或怀疑疾病相关的检查都能提供纠正机会。
- 规则：检查策略 精简（仅必需检查）/ 规范（必需 + 支持）/ 全面（再加鉴别病的必需检查）；接诊范围 能力外直接转诊（问诊后发现必需检查做不了或无门诊治疗方案即转）/ 尽量处理（先做能做的检查再定）。
- 结局：按 timely / delayed / missed 抽取 T002 的四类结局。delayed 判定：到院到离院超过分级时限（I 30、II 90、III 240、IV 480 分钟）；missed：最终诊断错误。结局在离院 3 天后随访揭晓（游戏简化）。误诊且未死亡的患者 60% 在 1–3 天后返诊，返诊时原病历补标“初诊误诊”。
- 候诊耐心：III 级 210 分钟、IV 级 150 分钟，超过自行离开；19:00 仍未完成的患者约次日。
