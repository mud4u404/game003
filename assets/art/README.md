# v02 参考画风的运行时素材

以 `art/concepts/v02/01-clinic-2d.png` 为画风参考，通过内置 image_gen 生成透明 PNG，并实际用于 Canvas 场景。原始输出复制到本目录，未用程序重绘或修改图片像素。

- `characters-v1.png`：5 名工作人员、7 组患者，以及部分坐姿。
- `idle-v1.png`：7 类患者和护士的双脚落地站姿，登记、排队和待命时不再冻结跨步图。
- `staff-work-v1.png`：两名医生及接待员的记录、抬头交流与说明手势，共 9 格；工作动作由服务阶段驱动。
- `walk-v1.png`：7 组患者与护士的跨步/并步关键帧，按行走距离轮换，水平方向镜像；尚非完整四向动画。
- `seated-v1.png`：与 7 组患者和接待员对应的坐姿。
- `furniture-v1.png`：诊疗床、办公桌、柜子、椅子、接待台、推车、植物、洗手台与诊凳。
- `atlas.json`：各素材的有效像素区域。生成图集并非严格均分，不能直接按格子切图；这些区域经透明度分析与目视核对。
- `prompts.json`：生成提示词。使用内置工具，没有调用 CLI 或外部 API 密钥。

`src/appearance.js` 根据患者已有身份选择稳定形象和身材尺度，不消耗世界随机源，不修改存档。同一患者不会随帧数或重新打开改变外观。年龄影响可选形象，不能借此推断患者诊断。

这是第一批可用素材，仍有重复原型、个别透视与遮挡差异。已接入步态关键帧、起坐过渡与简单工作动作；图集每行使用统一比例与脚底锚点，避免宽窄步态被独立缩放。当前仍没有完整前后方向、骨骼起坐或具体医疗操作动画。后续在该体系上迭代，不退回统一几何小人，也不把素材接入宣称为完全还原效果图。

本轮前台问题的原因不是坐姿 PNG 缺失，而是场景没有给前台配椅子、人物与柜台分别硬编码坐标。`seating.js` 现在统一定义座位，人物按坐垫接触点对齐。新工作图集按每行统一尺度、下半身锚点稳定位置，不能用每格独立居中去绘制伸手动作，否则人物会左右跳动。透明 PNG 原图未改，裁切与锚点保存在 `atlas.json`。
