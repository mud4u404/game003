# v3 产品基线（2026-09-30）

## 本轮用户确认

- 目标是把 **Project Hospital 的核心体验**做成适合手机的中国医院经营游戏：玩家亲自规划医院、布置房间和设备、配置人员，观察患者诊疗与医院运营，并不断调整布局和能力。
- 忠实于深度建设、患者流程、诊断与运营的玩法关系，在触控、信息密度和游戏节奏上改良。
- 场景与角色采用中国医院语境；医生、护士、患者是中国人。中文医院标识、门诊大厅、导诊/分诊、检验、放射、病房等应从空间组织与流程体现，而不只替换脸。
- 不清空 `game003`：旧原型作为参考，正式方向从 `/v3` 独立建立。旧存档保留。

## 产品判断，待原型验证

### 玩家循环

规划/建造 → 配设备和人员 → 开放诊疗能力 → 观察患者完整路径与排队 → 找出瓶颈 → 改造或扩建。玩家可以查看每位患者的病历及医院统计；直接操作和观察都应有价值。

### 手机交互

竖屏 9:16，2:1 等轴剖视。单指平移、双指缩放；长按预览房间占地，拖动放置，松手前显示能否放置以及原因。房间模板可快速生成基础配置，玩家仍可独立调整墙门和设备。点患者/房间/员工，统一从底部抽屉查看与操作。按钮尺寸和文字需真机检查。

### 首个可玩闭环

一层小型医院，门诊大厅和导诊/分诊、两间诊室、检验室、X 光室与三床病房。玩家至少能放置/移动房间模板、连通走廊、配置必要设备与岗位；患者从到院到问诊、检查、复诊、治疗或转诊、离院。房间缺设备、无人值班或路不通时，患者须明确等待或转诊，不得穿墙、瞬移、无端完成服务。先采用少量经核对的病例，再扩充医学库。

### 时间与保存

旧版的“现实时间 1:1、不能暂停或加速”不沿用于 v3。采用模拟时间，首轮操作目标是暂停、1×、快进，具体每档倍数通过触屏测试定。建造时可暂停，恢复后患者继续。离线补算与简报暂不作为第一里程碑，避免绕过可观察的建设反馈。新存档使用独立版本与键，不读取或覆盖旧存档。

### 视觉与原创边界

以用户最近选定的参考图为审美方向：克制、专业、手绘质感的等轴医院，成人正常比例，中国医院空间与中文导视。具体美术、地图、图标、文字、病例数据、代码与音效自行创作；不复制原作资产或界面。

## 尚未决定

- 精确模拟时间倍率、建筑自由度与模板默认设备、楼层扩张方式。
- 中国医疗制度在经营数值中模拟到什么深度，医保/收费口径与医院等级的玩法边界。
- 美术资产管线和引擎选择。先验证手机触控、性能和建设/患者闭环，再锁定长期技术栈。

上述是待验证的设计空间，不把旧 `GAMEPLAY.md` 的“院长不参与诊断、助理汇报中心、现实时间制”等自动当成 v3 决定。是否让玩家亲自介入个别疑难诊断，留待玩法原型检验。
