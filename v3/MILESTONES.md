# v3 开发顺序

| 阶段 | 可检查的结果 | 完成定义 |
|---|---|---|
| 0. 产品与模型基线 | 独立 v3 文档、建造/路径/服务核心模型 | 旧版无改动；自动验证房间连通、资源不足、患者检查后返回 |
| 1. 可操作的建设场景 | 竖屏等轴场景；单指平移、双指缩放、房间模板预览与放置、碰撞和走廊连通提示 | 390×844 与小屏真机或同等浏览器触控验收；玩家能不看说明建成诊室 |
| 2. 活着的医院 | 至少 20 名患者、诊室/检验/X 光/病房的排队与人员工作、查看患者路径 | 连续运行和刷新后无人无故卡住；每个事件与场景位置相符 |
| 3. 深度管理 | 独立设备配置、招聘与排班、基本现金流、搬迁/扩建 | 玩家能从排队或收支发现问题，并通过建设或人员调整改变结果 |
| 4. 美术与内容 | 原创中国医院资产、人物动作、经审读的首批疾病路径 | 画面、中文信息和诊疗逻辑在手机屏幕上可读，医学内容经专业审查 |

每阶段以正常游戏入口观察为准，测试页只供调试。后续开发应先做阶段 1，避免继续扩写旧版自动报表系统。
