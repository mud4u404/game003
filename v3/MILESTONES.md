# v3 阶段与用户确认点（草案）

| 阶段 | 可审查样例 | 用户确认后才进行 |
|---|---|---|
| 0. 玩法校准 | 已确认自动运行与玩家可选择检查/诊断/治疗；接着展示一位患者的证据递进、医生/设备/流程因果样例 | 病例模型与诊疗引擎 |
| 1. 美术定向 | 同机位、同流程节点、9:16 的中国医院场景比较；成人角色、候诊与诊室清晰可读 | 美术资产和场景实施 |
| 2. 可玩诊疗切片 | 标准配置医院，一位患者完整就诊，数位患者同时候诊；可旁观及接管病例 | 扩充病种、科室和患者量 |
| 3. 医院能力经营 | 按标准新增科室、设备和人员，病例可用检查与治疗范围随之改变 | 经济、排班、扩张平衡 |

旧版 `v3/src/hospital.js` 是临时技术夹具，不把其中的固定病例路线当成阶段 0 已完成。三种美术图为预览，不入游戏资产，等用户选定。每一阶段先给用户看到样例并确认；医学内容需另行核验。旧版本和存档保持独立。
