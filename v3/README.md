# v3：手机端中国医院模拟

这是新的产品与技术起点。旧版 `/` 和 `/v2/` 仍可运行，旧存档不迁移也不清除。v3 目前只有**临时规则夹具和自动验证**，尚无玩家画面或诊断引擎。

本目录的 [PRODUCT.md](PRODUCT.md) 记录本轮确认的方向、第一版范围和待验证问题；[MILESTONES.md](MILESTONES.md) 记录开发顺序。它们优先于旧版 `GAMEPLAY.md` 中与 v3 冲突的条目。

运行首个模型验证：

```sh
node --test tests/v3/*.test.mjs
```

`src/hospital.js` 是上一轮建立的最小夹具：网格建房、走廊连通、必要设备与人员、按预设路线排队及返回诊室。用户已明确以可观察、可介入的诊断过程为核心，因此该模型**不能作为正式诊疗架构**。时间由调用者按模拟分钟推进；示例路线和时长不能作为医学内容使用。

二维等轴画面实际代码样张见 [art-probe/README.md](art-probe/README.md)；这只是美术可行性验证，与诊断模型尚未连接。
