# v3：手机端中国医院模拟

这是新的产品与技术起点。旧版 `/` 和 `/v2/` 仍可运行，旧存档不迁移也不清除。v3 目前是**规则模型和自动验证**，尚无玩家画面。

本目录的 [PRODUCT.md](PRODUCT.md) 记录本轮确认的方向、第一版范围和待验证问题；[MILESTONES.md](MILESTONES.md) 记录开发顺序。它们优先于旧版 `GAMEPLAY.md` 中与 v3 冲突的条目。

运行首个模型验证：

```sh
node --test tests/v3/*.test.mjs
```

`src/hospital.js` 是与渲染无关的最小模型：网格建房、走廊连通、必要设备与人员、患者排队及检查返回诊室。时间由调用者按模拟分钟推进，尚未接入手机触控、导航动画、经济或真实疾病数据库。示例病例和时长都是开发夹具，不能作为医学内容使用。
