# 专业知识库计划

更新日期：2026-09-28。用户是非专业人士，要求开发方构建专业的医学知识库和医疗机构运营知识库，使游戏中的疾病、诊疗、科室、人员与经营规则都有依据。本文是计划和首批方向，**尚未建成**；标注“待核对”的条目必须对照原文或权威资料确认后才能写入游戏数据。

## 基本原则

- 每条知识带来源（指南、国家标准、教科书、官方统计），写明游戏中的简化方式和未覆盖范围。
- 数据与代码分离：知识库以结构化数据文件保存（计划放在 `data/`），游戏逻辑只读取数据，便于审阅和扩充。
- 医学内容未经临床专业人员审阅前，游戏内外都不宣称“临床准确”。游戏不提供真实医疗建议。
- LLM 不能自行编造疾病规则或数值；它最多用于生成患者叙述文字，且必须遵守知识库给出的事实。

## 一、医学知识库

每个病种一条记录，字段草案：

| 字段 | 内容 |
|---|---|
| 病种与所属科室 | 名称、ICD-10 编码、首诊科室、可能涉及的科室 |
| 流行病学 | 按年龄、性别、季节的相对发病率（用于城市需求生成） |
| 临床表现 | 主诉、症状/体征及出现概率 |
| 分诊 | 紧急程度分级规则、危重表现 |
| 鉴别诊断 | 需要区分的相似疾病 |
| 检查 | 需要的检查项目、典型结果、所需科室/设备/人员 |
| 诊断依据 | 确诊条件；诊断难度（影响医生误诊概率） |
| 治疗 | 门诊/住院/手术方案、所需能力、疗程、常见并发症 |
| 结局 | 不同处理下的好转、恶化、死亡风险（简化分档） |
| 转诊条件 | 本院能力不足时如何处理 |
| 费用区间 | 参考收费（待核对地区标准） |
| 来源与简化说明 | 资料出处、审阅状态 |

首批建议 20 个常见病种，覆盖小型综合医院的日常接诊：
- 内科：上呼吸道感染、社区获得性肺炎、急性胃肠炎、高血压、2 型糖尿病、慢性阻塞性肺疾病急性加重、心绞痛/急性冠脉综合征（识别并转诊）
- 外科：急性阑尾炎、胆囊炎/胆石症、软组织损伤与清创缝合、四肢骨折、腹股沟疝
- 妇产科：早孕检查、盆腔炎
- 其他常见：尿路感染、过敏性皮炎、急性扁桃体炎、腰椎间盘突出、脑卒中（识别并转诊）、中暑

检查与设备库、药品/治疗库、人员能力库作为配套数据，与病种相互引用。

## 二、医疗机构运营知识库

- **机构类别与设置标准**：诊所、门诊部、一级/二级综合医院的床位、科室、人员、设备和面积要求。参考国家卫健委《医疗机构基本标准（试行）》及后续修订（待核对原文与现行版本）。例如一级综合医院的科室下限，常见表述为临床科室至少有急诊室、内科、外科、妇（产）科、预防保健科，医技科室至少有药房、化验室、X 光室、消毒供应室，床位 20–99 张（待核对）。
- **人员**：医师/护士/技师的资质、执业范围、合理配比与薪资区间（按虚构城市的档次设定）。
- **科室运营**：门诊量与诊室数、检查设备周转、病床周转、药品库存与采购。
- **财务**：收费结构（挂号、诊查、检查、治疗、药品、住院）、医保结算的简化、固定与变动成本、贷款与股权融资条款。
- **管理制度**：分诊、首诊负责、转诊、会诊、质量与安全、投诉处理等制度，作为院长“规则制定”的选项来源。

## 三、起步建议如何产生

开局时，游戏根据现实标准和所选城市的需求数据，给出两三种起步方案（例如“综合门诊部”“一级综合医院”），并说明各自的门槛、投入和能接诊的病种范围。院长可以采纳、修改或完全自定。哪个科室最终能做强，由长期经营结果决定（见 GAMEPLAY.md“时间会给出答案”原则）。
