# 从零筹建一家医疗机构

2026-09-27。用户已确认：中国大陆的虚构城市。本文保留设计与专业依据，0.3已实现下述有限筹建闭环；未列入实现范围的内容仍是设计，不代表已经可操作。

## 用户明确要求与玩家身份

玩家从零参与选址、选择机构类型、招募、决定科室/治疗/服务及其配套。资金不足可以考虑贷款或延后投入；空间不足可以扩租或搬到更大场地。玩家仍是投资者/所有者，不要求亲自分诊、配药或逐个安排员工动作。此前自动提供四个房间、固定医护并直接营业，只是流程测试原型，不能再作为最终开局。

投资者选择战略与预算，机构的医学负责人对临床范围、质量和专业岗位负责。为契合投资者身份，首版筹建可采用由玩家投资的单位设置诊所，并聘任符合要求的主要负责人；不能默认一个无医生资格的个人可以用个人医师身份备案。具体设置条件以适用制度为依据。

## 专业依据与使用边界

本次查阅国家部门发布的正式规定和政府转载文本，不将2022年的征求意见稿、已被替代的2010年诊所标准当作现行准入标准。虚构城市仍需选定地方实施规则；以下仅建立国家层面的游戏内容依据，不是开办真实诊所的完整办事指南。正式医疗内容需要逐条专业审阅。

- [《诊所备案管理暂行办法》正式文本，国卫医政发〔2022〕33号](https://app.www.gov.cn/govdata/gov/202212/28/495617/article.html)：诊所定位；个人设置与单位设置的负责人条件；备案资料中的布局、租赁、人员、设备和药品清单；地址/科目等变更；按备案科目服务。
- [《医疗机构管理条例》2022年修订文本，政府公开页](https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/202308/t20230810_3219669.html)：机构类别、登记与诊所备案、与业务相适应的设施和人员、变更、诊疗科目与转诊。不能把诊所/门诊部/医院设计为只靠经验值自动更名的等级。
- [重庆市铜梁区卫健委转载的正式办法与2022年诊所基本标准](https://www.cqstl.gov.cn/bm/qwsjkw_71116/zwgk_70831/zcwj/qtgw_70838/202304/t20230420_11897445.html)：用于核对普通诊所等具体类型及基本条件。该市当地换证流程不是虚构城市自动套用的全国规则。
- [《医疗机构药事管理规定》](https://www.nhc.gov.cn/wjw/gfxwj/201103/3df77cb6091b4694be3afd8fcd68a4b5.shtml)和[《处方管理办法》](https://www.nhc.gov.cn/wjw/c100221/202201/6a4ee53e4a3a407fbd9f520e1e2662c5.shtml)：药事职责、处方审核、调配核对和用药指导。游戏目前“独立药房配置一名药师”是具体服务方案，不宣称所有诊所一律必须建独立药房或药学部门。
- 具体疾病路径依据仍见 `MEDICAL_MODEL.md`。医院机构制度、临床指南与经营测算是三个知识层，不能互相替代。

## 必须分开的四个概念

1. 机构类别：诊所、门诊部、医院等法律/管理类别。诊所主要提供常见、多发疾病的门诊诊疗，不设住院病床；院内诊察床不等于住院床位。
2. 诊疗科目：获准并具备相应人员能力的专业范围。普通诊所并不天然具备所有专科，更不能把“门诊”理解成什么都能治。
3. 实体房间/功能区：诊室、采样区、药房、处置区等空间。房间数量不等于学科数量；功能能否共享取决于项目、布局、感染防控及容量，不能一概合并或一律独立建房。
4. 医疗服务：一次问诊、某项检查、处方续配、换药、随访等具体行为。是否开展取决于机构范围、人员、设备、药耗、质量流程、适用患者与接续能力。

可开展的服务 = 范围允许 ∩ 合格且实际在岗的团队 ∩ 场地设备满足 ∩ 药耗/外部支持可用 ∩ 质量与应急安排就绪。

这是一条有明确缺项解释的能力校验，不是让玩家点亮科技树后凭空增加治愈率。也不是允许玩家为了现金流关闭最低质量保障。

## 玩家看得到的筹建过程（拟实现）

### 1. 城市与选址

开局展示城市地图与真实由世界模型生成的社区资料：人口结构、交通可达性、已有医疗供给、潜在需求、租赁条件、面积/楼层/布局、房屋适用性及扩租机会。不是“老人社区必然赚钱”或“建内科就刷新内科病人”。调查数据是估计区间，不是所有潜在病人的全知列表。

选址与机构定位应允许来回调整，先看候选方案再签租约。总面积足够也可能因通道、给排水、分区或医疗用途不适合；不能仅比较每平方米租金。签约时应看到押金、租期、装修期、租金开始日及退出/恢复成本，避免不可见的事后惩罚。

### 2. 机构与服务定位

首版先完整做普通诊所的创办流程，长期保留口腔等其他类型和门诊部/医院发展方向；只有真正具备对应专业内容时才开放选择。不能展示五种可点机构但全部使用同一批全科病例和房间。

让玩家先选服务人群与几项初始服务。医疗负责人据此提出可行的人员、空间与合作清单。例如成人常见病门诊、已知高血压随诊可以组成一种开局方案；这不是唯一正确路线，也不是已获用户选择的经营方向。

### 3. 招募与岗位

先聘任/确定医学负责人，再根据服务招募医护和相应专业人员。候选人展示执业范围、可承担项目、工作时间、薪酬和稳定性；声望高不代表能跨专业工作。关键岗位可由满足条件的人兼任，不能为了界面齐整强制开局雇一位纯行政院长。

开业前查看“谁负责、何时在岗、缺岗怎么办”。不再让一名护士全天候同时采血、评估、操作所有设备；诊所营业时段与排班要参与容量计算。日常排班和补货交给管理层，玩家只决定预算与服务时段。

### 4. 服务反推空间与配套

| 拟提供的服务 | 需要落实的能力 | 未具备时的处理 |
| --- | --- | --- |
| 成人门诊评估 | 相应医师、问诊查体条件、病历与分诊/警示识别 | 不接受超出范围的常规预约；突发急症启动能力内救助与转诊 |
| 已知慢病随诊 | 既往资料、测量条件、复评随访、必要检查与转诊接续 | 限制可承接病例，补齐信息或转上级评估 |
| 采样后委托检验 | 合格采样人员与空间、身份/标本核对、保存运送、合作实验室及报告处理 | 不把采到样本当成已完成检验；无法落实交接时安排外部就诊 |
| 院内处方调配 | 对应药事人员/职责、药柜及储存、采购库存、审方核对与用药说明 | 外部药房接续；不让护士/接待自动充当所有药学角色 |
| 某项设备检查 | 项目允许、设备、操作与判读能力、质量维护 | 未配置就明确外部承接，不能写“检查室”便自动获得所有检查 |

不是每个患者都要经过每个房间；服务按临床需要触发。过度检查或不必要治疗不能设计成无代价的增收策略。

### 5. 资金与融资

以下是经营模型建议，不是现实银行报价、贷款获批承诺或投资回报估计。

- 开业前支出：押金、装修、设备、信息系统、首批药耗、招聘/筹备工资、必要手续与服务合同。
- 开业后现金支出：工资、租金、采购、维护、废物处置、外部检查、税费及借款本息等，按实际适用内容建模。
- 营业收入、利润、银行余额分别记录。库存采购会先占用现金，设备投入也不会因月底账面盈利自动回收；后续若加入医保或机构结算，要建回款周期，不能假设开业自动取得医保定点。
- 贷款需要明确授信依据、额度、利率、期限、还本付息方式、担保/抵押条件（如适用）和拒贷可能；不要把贷款做成无条件加钱按钮，也不要任意虚构现实固定利率。
- 每次重大投入展示保守/中性/较好需求情景下的未来余额和缺口，区分新增能力与新增患者量。玩家可比较分期投入、租赁设备、外部合作、延后扩张和借款。
- “等赚钱再开”只能适用于已经营业且可能产生现金的业务之后；尚未开业不能靠等待生成营业收入。经营亏损时等待本身会消耗储备，系统需要提前解释。
- 不拿当前原型的 ¥/分钟、30分钟建药房或默认18万开局当作现实筹建预算。下一阶段必须重新建立经营时间与金额标尺，保留现实时间推进与离线同规则。

### 6. 准备就绪与开业

筹建面板只呈现必要决定与明确缺项：主要负责人/专业人员、服务范围、房屋布局、设备药耗、合作交接、资金和相应备案/登记。系统解释缺项影响哪项服务，允许缩小计划，不应只显示笼统红色“等级不足”。

玩家确认开业；首位患者依据城市需求及机构选择到访，而非教程强塞特定病种。日常运作由团队承担，投资者通过观察、交班与质量/经营复盘继续调整。

### 7. 扩租、迁址与机构成长

空间不足可比较内部重排、相邻扩租、整体迁址，未来再考虑分院。比较新租约/装修、旧租约退出、设备安装校验、地址变更、通勤与患者可达性、过渡期双重成本和业务中断。保持原机构身份、病历、随访、债务与历史；迁址不是新建一个机构并复制资金。

搬迁由管理层计划过渡日程和患者接续；能延期的预约重排，不能中断的照护需要合作承接。不要求玩家在特定分钟上线才能避免损害。诊所发展为医院涉及新的机构条件与服务能力，不靠扩大面积自动完成。

## 让专业知识帮助决策，而不是制造考试

玩家选项目时，负责人用一段短解释列出必要条件、当前缺项、成本及替代方案；可展开查看资料依据。系统不替玩家决定“最佳路线”，也不让玩家背诊断标准或亲自开药。经营测算存在不确定性，专业底线必须确定。

知识条目至少保存：内容类型（法规/标准/指南/经营假设）、适用地区/机构/人群、来源与版本、生效与复核时间、覆盖范围、前置能力、不能承接的情形、游戏抽象、审阅状态。LLM 可以解释已知事实和建议方案，不能自创许可条件、疾病结果或贷款报价。

## 实施顺序与验收

下一阶段先做“尚未开业”的筹建存档，以及选址→范围→招聘/配置→资金方案→开业的小闭环，沿用已有患者路径作首批真实负荷。没有人员/设备/空间的服务不能运行，尚未开业没有收入；取消方案不消耗已未承诺的钱，签约和采购有一致账本。

随后接入真实营业时段/岗位容量与预算，再实现债务和迁址。旧存档保留为已营业机构；不得未经用户选择清档重开。未来提供明确的新建游戏/新档槽，不用开发验收页充当开局。

本轮仅落实：患者姓名/性别/年龄与形象的一致性、可选择筹备的院内药房（房间、岗位、流程、库存/补货）及院内外服务的明确展示。招聘市场、选址、贷款、搬迁和完整筹建界面尚未实现。


## 0.3 已实现范围（2026-09-27）

- 默认 `/` 是独立筹建档案 `meiao-founder-v1`，旧 `meiao-clinic-v1` 在 `/?slot=legacy` 继续。各自独立写锁。新建不覆盖原诊所，也不搬移既有患者或现金。
- 三个固定场地：96/148/220㎡，三/四/五个功能单元；押金、装修、月租、潜在到访可达性、预算约束实际参与模拟。地区人口结构尚未建模，老社区等描述不能被当成已实现的疾病分布。场景仍复用模块化平面图，非按面积绘制的自由装修系统。
- 当前机构类别只有普通诊所；成人基础门诊、慢病随诊是同一类别内的两个起始服务组合。口腔、住院医院未开放。成人门诊必需，可选高血压随诊、采样送检、院内既有处方续配；开业后可追加前两项，药房需先招募药师再筹备。没有院内采样时，检查交接合作机构，不伪造本院已采样记录。
- 选择虚构医学负责人、护士、接待及按需药师。同岗位候选人当前能力/报价相同，尚未建立个人能力成长或动态招聘市场。新档不强行配纯行政院长。扩诊/独立采样仍以组合项目自动聘任新增岗位，未来要拆解。
- 五步筹建：选址→定位/服务→团队→资金→复核。选择不扣款；缺必需岗位/服务或签约后不足3万元储备不能签约。签约实际扣押金、装修、配置和招募费用，等待后手动开业。签约后即承担固定成本，不开业没有营业收入。
- 资金：18万初始资金；自筹或6万/12万模拟启动贷款，6%/7%模拟年利率，每30天等额本金、共12期；欠款保留，利息与偿还本金分开，欠付限制投资。没有真实授信/担保/拒贷、追加借款、重组或完整破产机制。以上资金、租金、工资、费用均未经济校准，不是现实开办报价。
- 营业：北京时间工作日09:00—17:00，真实时间1:1。固定工资、租金、维护按月报价、每24小时按月额/30日结；已在院照护结束后员工离场，已雇佣名单仍可查看。无轮班、节假日调休或可编辑营业时段。城市需求独立产生，可达性/开门/能力只改变是否接诊；没有建科室就刷同类病人的逻辑。
- 迁址：新押金、装修、搬运及旧租退出费用先扣，保留3万元储备；暂停新接诊24小时且等现有患者完成，原押金返还；病历、待报告、随访、员工和债务保留，复诊顺延。押金无损退还、一天迁完、筹建30/60/90分钟都是显式演示参数，不代表真实行政/施工时长。
- 医学/备案目前只是有限规则与配置检查，并非真实完整执业准入判定；此前专业依据仍需本地化与临床审阅。更大医疗机构、真实疗效评估、科研/声誉、媒体、LLM、医保结算和云端运行仍未实现。
